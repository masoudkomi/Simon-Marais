## R8A. Exact backward fork at a full-width canonical level

For a finite canonical prefix with integer value N, its UNIQUE
canonical parent and last digit are

    P(N)=floor(qN/p), a(N)=qN-p floor(qN/p).        (A1)

This is simply modified division, with0<=a<=p-1=q. It applies to
nonnegative N including N0 and to every fixed padded prefix level.

Let H>=q-1 and consider the q consecutive child prefix states

    I_H={H-q+1,...,H}.                             (A2)

Write H=pk+r with0<=r<=q. Then:

* If r=0 or r=q, P is injective on I_H, so there are q distinct
  parent prefixes. The upper child's last digit is respectively0 or1.
* If1<=r<=q-1, P(I_H) has exactly q-1 elements. The ONLY merger is
  children pk and pk+1, both with parent qk. Their last digits are
  exactly0 andq. The upper child's last digit is p-r, which lies
  in{2,...,q}.

### Proof

For N=pl+s,0<=s<=q,

    P(N)=ql                 if s=0,
    P(N)=ql+s-1             if1<=s<=q.             (A3)

Thus successive integer children have successive parents except for
the single pair pl,pl+1. The interval I_H has length q-1=p-2 and
can contain at most one such pair. It contains that pair exactly
when1<=r<=q-1. In those cases it contains pk,pk+1; in the two
remaining cases it misses respectively pk+1 or pk, so has no merger.
Formula(A3) also gives, in the merger case,

    P(I_H)={qk+r-q+1,...,qk+r-1},                 (A4)

a consecutive set of q-1 parents. Finally(A1) gives a(pk)=0,
a(pk+1)=q, a(H)=p-r for r>0 and a(H)=0 for r0. This proves all
assertions, including boundary k0, when the merging parent may be0.

If a REAL fiber already has q distinct canonical words at the child
level(A2), it still has q full words after a common radix translation.
Nevertheless, in the merger cases only q-1 prefixes distinguish
those words at the earlier level: the pair has a shared parent and
then takes its legal0/q branches. Consequently preservation of the
FULL fiber does not imply preservation of q DISTINCT ordinary
prefix states backward. F5B's largest-ceiling-path conclusion applies
only AFTER all full words have separated; applying it before their
last fork omits exactly this possibility.

This is a conditional description of an actual maximal fiber, not
a construction of one at q10. It counts the local parent map only
to identify the precise missing predecessor inference; it supplies
no forbidden ordinary order or new empirical orbit table.

## R8D. Literal real beta-expansions do not repair the integral interface

The usual real binary beta expansion of a value uses arbitrary
digits epsilon_i in{0,1} and evaluates sum epsilon_i beta^(-i).
Its initial prefix states need not be ordinary integers. In the
canonical convention(I2), an infinite root word starts at N0=0.
Its FIRST nonzero digit must be q: qN_next=a with1<=a<=q forces
a=q,N_next=1.

This gives a concrete interface obstruction. No nonzero infinite
binary root word can become canonical by simply retaining its digits
or uniformly scaling them by any fixed allowed integer c:

* For1<=c<q, its first nonzero digit c is not legal from state0.
* For c=q, the first nonzero digit is legal and gives state1, but
  the next digit is0 orq. Then p*1+a is1modq, so the next prefix
  cannot be an ordinary integer.

Larger c is outside the full alphabet. Inserting common leading
zeros or making a common global radix translation does not alter
this first-nonzero obstruction. This concerns literal uniform digit
maps, not arbitrary state-dependent normalization/carries, and
does not say that the real value lacks some DIFFERENT canonical
representation.

An eventual binary TAIL after a genuine finite ordinary seed is
different: its seed must satisfy all of the congruences in(I2).
Those congruences are not supplied by standard real expansion
multiplicity. For example the binary tail(10)^infinity at beta11/10
has a perfectly convergent real value. Were it an integer-prefix
ceiling tail, iterating its recurrence in Z_10 would force

    H0= -sum_(j>=0) d_j10^j/11^(j+1)
       =-(1/11)/(1-100/121)=-11/21.               (D1)

The denominator is prime to10, so(D1) is a legitimate10-adic
identity, but its unique rational seed is NOT an ordinary positive
integer. This is the previously known all-B rational behavior,
used only as an explicit interface check, not a new survivor or
a replacement for the unresolved nonperiodic case.

Primary literature on unrestricted real beta expansions proves
large multiplicities in its own language. Those conclusions have
no canonical integer-seed consequence until a map preserving EVERY
prefix integrality and the chosen radix is proved. The literal
maps above fail. A richer map would have to address the ordinary
seed itself; merely preserving the real series, normalizing an
unrestricted beta shift or producing real tails is insufficient.
