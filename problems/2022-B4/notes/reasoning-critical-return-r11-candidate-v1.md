The original Dubickas--Mossinghoff stopped ceiling map has ONE fixed

termination theorem for this R. Lagarias--Sloane's class P_r has a

maps need not all be monotone. CR11C therefore adds something beyond
just noticing that R is not monotone: it excludes a GLOBAL unbounded
monotone height transfer to any such fixed positive expanding-slope
map with bounded corrections. The result does not exclude every
possible reduction, nor does it furnish a missing source theorem.

Dubickas's2009 closed-interval result concerns fractional parts of

That hypothesis is not supplied by an unknown-duration return map.
The theorem's width1/p, p<q^2 and all-index conditions cannot be
replaced by a controller alphabet, an interval union, or selected
return samples. No source theorem is imported as a NEW proof step.

The exact remaining task is to control an ACTUAL aperiodic safe
itinerary or one-sided ordinary tail. A phase-dependent, nonmonotone

proof identifies a broad unavailable shortcut, rather than claiming
that none exists. Universal equality, an actual infinite ordinary

## 7. Issue log and failed approaches

* **N11-02, unknown time.** Cooperativity of F cannot order first events

* **N11-03, weak monotonicity.** Strict input/output order alone would
  only refute injective H. The overlapping intervals are necessary to
  handle flat H and derive eventual constancy. Closed by§3.
* **N11-04, nonmonotone scalar maps.** Lagarias--Sloane's whole class
  P_r is not assumed monotone. Merely using CR11B would leave that
  loophole; CR11C treats bounded corrections separately. Closed only
  for its monotone-H GLOBAL hypothesis.

  does not control log/loglog height scales. The fixed family plus
  output interval bounds proves§4 without such a comparison. Closed
  within its exact hypotheses; lambda1 remains OPEN.
* **N11-06, fractional-part theorems.** No fixed-xi, all-power interval
  of the required width has been deduced for the full unknown-clock R.
  Dubickas's closed-width theorem therefore does not settle it. OPEN.
* **N11-07, canonical multiplicity/normality.** The accepted reductions
  still lack the ordinary two-residue termination or maximal-fiber
  exclusion. A q-adic path or changing finite representatives do not
  provide one ordinary infinite seed. No new source assertion repairs

* **N11-08, permitted nonmonotone/clock bridges.** This obstruction is
  not a proof that every number-theoretic reduction fails. In particular
  physical time has slope beta while one return has unknown duration;
  retaining that clock is a materially different model. OPEN.
