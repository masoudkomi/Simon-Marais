## Finite residue graph

`residue_graph.py` uses state `(d=a-b,r=b mod60)` and control
`e=floor(b/60) mod10`, with the exact transition in proof.md P1. Within
the established strip it constructs 2,220 vertices and 22,200 controlled
edges. The full ordered edge list is deterministically regenerated by
the script and has SHA-256
`7510f9deebb8ca708fc97ae28bd8a34dee08b78bde39f18fddb84f4de88ab164`.

Deleting d=0 leaves 2,160 vertices and 21,120 edges. Pruning vertices
without a surviving successor deletes 48, leaving 2,112 that admit
arbitrarily long abstract avoiding walks. There are 77 cyclic strongly
connected components; the largest has 222 vertices. The self-loop
`(d,r)=(1,0)`, control e=0, is an explicit example.

Every full-graph state has some abstract path to d=0; exact reverse BFS
finds maximum shortest distance 12. Separately, the sign-based analytic
policy in proof.md is checked on all 2,220 states and has its measured
maximum recorded in the JSON. These finite graph computations are
supplementary evidence; the candidate density theorem has an analytic
path argument and does not use BFS as a proof premise.

The script checks the explicit finite-delay formula for N=1,...,40,
t in {1,2,7}, and r=0,...,19 (2,400 parameter triples) with exact integers.

**Limitation:** finite graph cycles do not establish an infinite positive
integer orbit. Finite control words do lift to congruence classes, but an
infinite word can demand a 10-adic value that is not an ordinary positive
integer. Even the candidate density-one theorem leaves a density-zero
exceptional set whose emptiness is unknown.
