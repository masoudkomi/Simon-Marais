# Profile-sensitive upper entropy: a quantifier audit

2026-10-18 UTC. Coordinator exploratory reasoning, **unverified**. This is
an attempted route and an explicit remaining inference, not a new upper-R
theorem, a review replacing the two OTHER R6 audits, or an annual solution.
Root is already excluded as an R6 contributor. No mathematical program,
enumeration, CAS or certificate replay was used.

The R6 finite origin model suggests testing progressively larger extension
buffers around a fixed local pattern. For a fixed finite support, arbitrarily
large locally valid extensions would give a global plane extension by a
diagonal compactness argument on a finite alphabet. Because the pattern set
on that ONE support is finite, the projected extension sets eventually
stabilize to the plane-extendable set. This observation supplies no known
effective stabilization time. More seriously, it concerns a fixed window;
the window size also grows in an entropy argument. It does not license a
diagonal choice of buffer and window that is known to have reached the
desired plane-pattern count.

The tempting next step was to impose near-affine height data as well. R6 PM3
is precisely an upper comparison for ACTUAL plane families close to one
strict rational affine lift on the WHOLE required buffer. At a fixed rational
frame it compares their counts with the canonical receiving count C_m, with
controlled boundary loss. It does not prove that arbitrary locally valid
finite origin blocks have actual plane representatives. The preceding
compactness observation does not remove that distinction at a known scale.

A different temptation was to use plane classes whose height deviation from
one affine map is bounded by a fixed K. Repeating a fixed receiving patch
could suggest bounded-deviation plane lower bounds after an exact periodic
gluing construction; that construction itself would still need to preserve
all edges, ranks, periods and counts. Even if established, increasingly
large K would give an increasing collection of lower approximations. An
upper certificate for each fixed-K class would not automatically be an
upper certificate for their supremum. Interchanging that supremum with the
window-size entropy infimum is the missing inference, rather than a new
proof of two-sided computability.

The R6 three-direction comparison makes the boundary issue concrete: the
unconditioned plane entropy can be larger than the full balanced-zonogon
entropy even along sectors approaching the same tile densities. Conditioning
on averaged composition therefore cannot stand in for the whole macroscopic
height profile and boundary ports. PM2's O(perimeter) completion supplies an
actual exterior, but its area can remain a constant multiple of the source
patch area, so it does not turn that completion into a negligible collar.

The useful target remains a finite upper count functional retaining the
entire prescribed boundary/profile, with a proof that its upper mass can be
matched by actual fine fillings. The accepted GR shape realization and the
R6 candidate's plane/full interface address geometric prerequisites; neither
alone supplies that mass comparison or an effective upper modulus. This
route is retained as a failed shortcut, with its fixed-window versus growing-
window quantifiers explicit, to avoid repeating it as a purported solution.
