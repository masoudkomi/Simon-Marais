finitely many rhombus angles. A countably distinct track perturbation
need not satisfy that global convention; the two-family grid already
shows why infinitely many crossing angle differences can result. It
would be wrong to cite a global finite-angle periodic extension for
that perturbed plane.

construction in Lemma 4.3's operative proof. Its turning identities,
opposite-edge pairing, finite-patch induction and corner insertion use
the existing finite track set, an embedded train-track-convex patch and
distinct directions on that set. No angle bound on outside faces enters
those steps. Those local hypotheses were independently checked above;
KS plus the uniform-area argument provides the actual perturbed plane.
The same finite construction as invoked is therefore justified. This
is a closed read-scope qualification, not an unresolved mathematical
extension, a new global theorem, or a reviewer change to the candidate.
