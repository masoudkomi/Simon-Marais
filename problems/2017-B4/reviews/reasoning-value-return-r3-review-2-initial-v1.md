## 2. The finite heap is the actual class invariant

For one internal class A on m labels, name the lth occurrence of
generator s_r by (r,l). There are K=binom(m,2) events. For a representative
word, order every pair with index distance at most one in the order it
appears, then take transitive closure. Every such relation is forward
in this word; consequently this is a finite poset, not merely a
potentially cyclic system of inequalities. For m=1 it is empty.

Swapping commuting adjacent generators changes neither the relative
order of noncommuting events nor the occurrence order of any one
generator. Thus the event IDs and the whole poset P_A are invariant.
Every representative of A is a linear extension. Conversely, any two
linear extensions can be connected by adjacent incomparable swaps:
move the desired first element left past the preceding elements, all
incomparable with it, and induct after removing it. In P_A, incomparable
elements necessarily have indices at distance greater than one, so
these swaps are precisely allowed commutations. Every extension remains
a representative of the SAME A. No braid move is introduced. The
longest permutation need not be fully commutative; no such hypothesis
is required for this statement about each individual commutation class.

After smoothing equal-color crossings, an s_r event meets current rank
tracks r and r+1. The list on rank r contains exactly indices r-1 and r
in their invariant order. All pairs on that list are comparable.
Conversely, any pair in the generating relation shares a rank: equal
indices share both ranks and successive indices share their intermediate
rank. Therefore the closure of the directed per-rank contact lists is
exactly P_A. This is the required rank-track order, not the different
order along one original labeled strand.

For an actual full class T above projected Q, OP1 says both ends of an
erased contact have the same canonical external gap index. Its proof
uses the initial consecutive block, current adjacency and the fact each
external projected track crosses either neighbor at most once. Equal
crossed-track SETS imply equal cardinalities. The new proof uses the
resulting same INDEX, without making the stronger necessary set
condition sufficient.

On any directed rank track the external-crossing count cannot decrease.
Thus the common index f(e) is weakly increasing on every contact list,
and hence on the entire heap. Each track crosses exactly a=n-m external
tracks, so f has values in {0,...,a}, including both end gaps. This gives
exactly the stated weak order-polynomial convention Omega_A(a+1).

Given Q, A and f, place both ends in their named gaps. The WHOLE internal
class fixes the complete merged ID list on each track, including events
meeting opposite neighbors in one gap. This supplies all within-gap
orders, after which accepted DC matching/routing recovers the original
class. There is no residual shuffle factor. Some abstract f fail the
prefix-set or other constraints of Q; counting them only enlarges an

## 3. HC1's equality has a special, complete inverse

There is no hidden internal B reversal to specify.

choosing a linear extension of each equal-level induced subposet. A

concatenation is a linear extension of P_A and a representative of A.
At stage j the list is

    B_1 ... B_j [one contiguous current A block] B_(j+1) ... B_a.

Perform its internal A events of level j at their indicated local ranks.

left across the ENTIRE block, stopping after the processed B prefix.
Every step is an adjacent swap. It preserves B order and preserves the
current A order after the bubble. This establishes the stage invariant

The final list is B in its original order followed by reversed A. Every

## 6. HC3: parity identity, limit normalization and comparison

Fix D>=2 throughout the n limit and choose balanced positive m_i. Set
delta_i=m_i modulo2. Expanding the DEFINITION of E_* gives

    S=(sum m_i^2-n)/2,
    E_*=(n^2-sum m_i^2+n-sum delta_i(n-m_i+1))/2,
    E_*+S=(n^2-sum delta_i(n-m_i+1))/2.

These are exact integer identities; the last parity sum is O_D(n),
not a term known to vanish when D grows with n. At fixed D,
sum m_i^2/n^2→1/D. Therefore S/n^2→1/(2D), E_*/n^2→(1-1/D)/2,
M/n^2→1/2 for M=E_*+S-1, and S/M→1/D. For all sufficiently large n,
S>0 and M>=S>0. Applying the elementary binomial entropy inequality,
including its s=0 or s=M limiting conventions, yields

    limsup n^(-2)log J_* <= (1/2)h_2(1/D)=g_D.

There is no M=0 division in this asymptotic application; finite empty
records were handled separately.

Coordinatewise monotonicity squeezes B(m_i) between B_D(p) and B_D(p+1),
p=floor(n/D). The accepted ALL-integer side-length limit supplies
