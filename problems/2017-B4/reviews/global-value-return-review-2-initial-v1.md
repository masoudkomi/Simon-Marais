## V1: reconstruct the finite code before counting

Fix consecutive initial blocks of positive sizes m_i summing to n. Delete
all ORIGINAL labels outside one block. At a retained internal event its
two labels were adjacent in the full list, so they are adjacent in the
restricted list. Every pair of retained labels crosses exactly once and
the terminal order reverses. Thus the restriction is a length binom(m_i,2)
reduced reversal. It defines an internal class A_i, not a word history.

An original allowed commutation exchanges events on disjoint position
intervals. If at most one survives this block restriction, the surviving
word is unchanged. If both survive, their four labels remain in disjoint
adjacent pairs after deletion; their restricted generators commute.
Consequently the induced A_i is well defined on full commutation classes.
Initial boundary order fixes all its labels, without another choice.

Smooth all events in A_i. These are rank tracks rather than original
labelled strands: crossing original labels exchange tracks at a restored
contact. An event at same-color ranks j,j+1 produces the directed symbol
plus on j and minus on j+1. Commuting generators have disjoint rank pairs and
alter neither a track's symbol order nor its symbols. Each event supplies
two ports, so the invariant lengths satisfy sum_r k_r=m_i(m_i-1).

Here is the necessary identification with the FULL smoothed diagram.
Deleting other colors leaves the same current relative order of this
color's labels. Smoothing internal events preserves that relative rank
between events; other-color events merely insert retained vertices along
these tracks. Therefore erasing those retained vertices gives exactly the
per-rank lists of A_i, including both end portions and repeated contacts.
This uses the order among one color, not a false identification of a rank
with an original strand throughout the diagram.

For a fixed projected block-reversal class Q, a color-i rank crosses every
other-color rank once. One direct reason is that the target reverses all
different-color pairs, while its word has exactly the inversion number
sum_(i<j)m_i m_j. No pair can recross in this reduced word. Hence each
color-i track has a=n-m_i retained vertices and a+1 canonical directed
gaps. Their names are supplied by the retained strand identities and
their orders, as in accepted DC; no choice of a global sweep names them.

For a track with k known ports, its nonnegative gap counts have
binom(a+k,k) possibilities. Counts assign consecutive pieces of its
already known symbol list to the ordered gaps. A list inside a gap needs
no further ordering or neighbour-bit choices. If a=0 there is one gap;
if k=0 there is the empty list. Both counts are one as required.

Given all these lists and placements, recover the complete DC decorated
diagram. For each neighboring rank pair, the kth port pointing toward

diagram. Cross-route at restored contacts, retain routing at the remaining
