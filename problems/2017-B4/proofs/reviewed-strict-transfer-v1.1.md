## Fixed frame and geometric notation

Take D=4, v_i=(1,i-1), VJ=I, rational J, and all ordered row minors
strictly positive. Fix independent u,v in the common positive cone,
det(u,v)>0, with a=Ju,b=Jv positive integral, and the single phase
producing A4's words U,W. All data are fixed before epsilon and L.
Let C_m be A5's complete weak-lens count between U^mW^m and W^mU^m.
Let

    s=lim_(m->infinity) m^-2 log2 C_m,

supplied by the exact A5 block construction, not a free-window theorem.
The canonical boundary is within C_J of the parallelogram
P_m={tu+rv:0<=t,r<=m}, and of the affine lift Jx. Its main Jordan lens
has count at least C_m/B_J for a fixed finite B_J, by bounded end lobes.

Consider P_L=x0+{tu+rv:0<=t,r<=L}, with a common affine offset c in
ker V. Actual source or reference tilings satisfy
||a_T(x)-Jx-c||<=C1 epsilon L on a sufficiently large fixed multiple
of sqrt(epsilon)L neighborhood of P_L. That neighborhood is tiled.
Small epsilon>0 and large L thresholds depend on these fixed data.

For this one fixed parallelogram shape there is c_shape>0 such that
concentric enlargement of its side parameter from L to L+2t separates
the two parallelogram boundaries by at least c_shape t. This follows
from the positive distances between the four parallel supporting lines,
whose displacements are t times fixed nonzero transverse projections.
Concentric shrinkage has the corresponding separation.

## ST1: extraction into one fixed canonical frame

There are constants A,K and epsilon0>0, depending only on the fixed
data, such that for 0<epsilon<epsilon0 and sufficiently large L every
family F of distinct restrictions to P_L as above satisfies

    log2 |F| <= log2 C_m + K(sqrt(epsilon)L^2+L),
    m=ceil(L+2A sqrt(epsilon)L).                         (ST1)

Choose one full-tiling representative of each restriction. CUT1 gives
an actual inner Jordan lens Omega_T, with both boundary paths positive
and comparable, inside an R=C_cut sqrt(epsilon)L neighborhood of P_L,
and containing its R-eroded core. The whole boundary retains the given
affine lift approximation. CUT2 bounds the lost information by a fixed
boundary-strip code, with O(sqrt(epsilon)L^2+L) bits.

Center a canonical size-m frame at the center of P_L. Its desired
initial corner is x0+(L-m)(u+v)/2. Round J times this corner plus c to
one integer vector z, and translate both the canonical physical frame
and its heights by Vz,z. A4 gives bounded physical and affine-offset
errors. This z, m and phase are fixed for the whole family F, not
chosen separately for different core fillings.

Choose A large enough that the shape margin dominates R and all bounded
rounding/trimming errors. Then the canonical OUTER main Jordan lens
strictly contains Omega_T and has vertex-to-boundary buffer

    t_buffer >= c4 A sqrt(epsilon)L

for a fixed c4>0 and large L. This conclusion uses the matching u,v
shape; near-flatness alone for an arbitrary lens shape would not imply it.

The outer boundary affine error E0 is bounded by a fixed C'_J and the
inner boundary error is E1<=C1 epsilon L. The A3 condition

    sigma(J)t_buffer>sqrt(2)(E0+E1)

holds for epsilon sufficiently small and L sufficiently large, since
sqrt(epsilon) dominates epsilon and sigma(J)>0 is fixed. It gives
ALL relative rank ranges and ideal tests, including both corners.
The translated-frame convention is essential; no independent rank
offset is assigned at a corner.

The repaired A2 annulus therefore pads each inner lens into the same
outer main frame. Its padding depends on the inner boundary only.
Given that boundary code, restriction recovers the entire inner tiling.
Appending fixed bounded end-lobe fillings maps the result to a tiling
counted by C_m. CUT2's strip record then recovers the original P_L
restriction. The extra inner word/offset code has O(L) bits.

For the coordinate bound, subtract one common integer vector nearest
Jx0+c from every input height. With x0,J,c fixed across F, the relative
heights in this region are O(L); absolute rank offsets do not add a
family-dependent factorial or unbounded coordinate choice. Thus the
fiber bound is exactly the one in ST1.

## ST2: insertion into any compatible actual reference patch

For every actual reference tiling satisfying the same buffered
approximation, one can keep its tiling outside a CUT1 Jordan lens and
insert at least

    C_k/B_J distinct interiors,
    k=floor(L-2A sqrt(epsilon)L),                         (ST2)

for the same sufficiently large A, after shrinking epsilon0 if necessary.
Take L sufficiently large that k is in the canonical main-lens range.

Construct Omega_T once using CUT1 and fix it. A concentric canonical
size-k main lens, with the one rounded integer offset from A4, lies
inside Omega_T. Matching shape, the CUT containment, and the choice
of A give the same lower buffer c4 A sqrt(epsilon)L. Now the OUTER
boundary is the actual Omega_T, with error E0<=C1 epsilon L, and
the INNER canonical boundary has bounded error E1<=C'_J.
The same A3 inequality applies with these roles exchanged.

The repaired A2 construction yields one annulus fixed before the inner
tiling varies. Keep the original reference outside Omega_T. Vary every
canonical main-lens filling; its count is at least C_k/B_J because
only bounded end-lobe factors were removed. Restriction to the chosen
canonical core recovers each filling. This proves the count and
preserves the actual original lifted boundary.

An arbitrary filling counted by C_k is NOT asserted to be uniformly
epsilon L-close to the affine lift inside the core. Only its boundary
has that approximation. This distinction does not affect A3 or counting.
The old and new tilings have uniformly bounded coordinate gradients
and agree on the outer boundary, so their lifts differ by O_J(L)
throughout the changed patch. If the patch is a window of diameter
eta times a global scale p, this changes the global normalized profile
by O_J(eta), which tends to zero with the window mesh. It does not
give an O(epsilon eta) claim.

## ST3: the exact local entropy sandwich

For fixed small epsilon, (ST1) and A5 give, for any source families
over a sequence L tending to infinity,

    limsup L^-2 log2|F_L|
       <=(1+2A sqrt(epsilon))^2 s+K sqrt(epsilon).

For reference tilings existing at every sufficiently large L, the
number of replacements preserving their fixed exterior has

    liminf L^-2 log2(number of replacements)
       >=(1-2A sqrt(epsilon))^2 s.

If references exist only on a subsequence, the lower statement is only
on that subsequence. There is no automatic all-scale reference claim
in ST2. Integer ceilings/floors and B_J affect normalized limits by o(1).
Letting epsilon go to zero compares extraction and insertion to the
same fixed-frame s. No continuity of s under slope changes or change
of the u,v frame is being asserted.

An irrational tangent can first be approximated by one rational strict
J' with VJ'=I, keeping a common recentered affine offset and enlarging
the error by O(||J-J'||L). That observation is not a claimed uniform
irrational-slope entropy theorem. Frame denominators and scale
thresholds must be fixed before taking L to infinity.

## Global recovery is still missing
