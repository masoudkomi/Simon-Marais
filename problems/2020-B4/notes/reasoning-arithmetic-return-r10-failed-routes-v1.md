## 1. Exclude mixed principal products using only odd class number

This is too strong. M10A--C give actual distinct rational primes,
balanced nonprincipal ideals and an actual integral Weil generator of
their principal product. The theorem retains a SPECIFIED type-sum image,
actual Frobenius/class data and exact unit correction. It does not merely
observe that a finite abelian group can have a zero-sum sequence.

The elementary F=Qsqrt(-31),norm(1+w)=10 example already has two
nonprincipal prime factors and odd class number3. It is a genuine

the proposed GENERAL odd-class prohibition, not to the contest conjecture.

## 2. Prescribing the right norm residue forces the original order

    sum a_x(a_x-1)=h(2q0+1)+h²p.

## 3. Arbitrary minus class patterns are all single-prime types

The actual realization theorem uses W=theta(C^-), not all ofC^-.

is imported here. A precise hand diagnostic is m12:

    K=Q(zeta12), E=Qsqrt3, u=1-zeta12,
    u*c(u)=2-sqrt3, (2-sqrt3)(2+sqrt3)=1.

## 7. Obtain the missing size from general effectiveness

The Chebotarev proof read here gives infinitude and positive density.
An effective least-prime theorem, even if separately imported with all
hypotheses, would give an upper bound for SOME prime in the prescribed
class. No argument makes that bound fit the one finite product q0,

also have to be an actual divisor of q0. No GRH, Linnik estimate,
unproved class-group smallness or unproved analytic uniformity is used.
