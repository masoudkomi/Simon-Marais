# Actual failed routes and the surviving arithmetic gap

2026-10-18 UTC. **Candidate reasoning - unverified.** These are actual
routes considered in this research, not a claim that every other route
fails. No numerical parameter scan was used to manufacture a result.

1. **Use the easy R8 solvability tests to construct a non-prime-power
   order.** The partial-factor application of the published norm bound
   blocks this hope: under the original odd ordinary class hypothesis,
   BOTH longinterval and exponentdivisibility tests force q primepower.
   In the exponent test the full class exponent must in fact equal the
   prime-power exponent ofq. This does not show that the FULL interval
   criterion is empty at every non-prime-powerq. Its cancellation can
   be mixed across rational prime factors, with no easy sufficient test.

2. **Factor an actual norm-q character into integral prime-norm Weil
   factors.** This fails structurally. At primep=q²+q+1 the known
   small-norm theorem excludes ALL smaller nonsquare integral norms.
   The q8,p73 existing character already cannot factor into norms2
   and4, despite q8 being a known prime-power order. Weil-indecomposable
   is not ordinary irreducible and does not force q prime. Factoring
   ideals does not automatically factor their Weil generators.

3. **The small-norm estimate was a new theorem.** Initial hand work
   rediscovered a coefficient-energy argument. Public primary discovery
   found Schmidt's2017 conference statement, then the operative
   Leung--Schmidt2019 author-version Theorem23 and complete proof.
   The result is attributed as PUBLISHED. The main's prime-case trace,
   frequency and support proof is a reconstruction, not a priority claim
   or an abstract-only theorem import.

4. **Apply that theorem to square partial norms as well.** It explicitly
   needs a nonsquare. For instance integer2 in Z[zeta73] has norm4,
   while73>4²+4+1. This exact trivial square example forbids the
   omitted-hypothesis extension. The longinterval proof selects an
   ODD prime exponent, and the class-order proof uses the ODD class
   order, precisely to make the tested norms nonsquares. A general
   layer decomposition of repeated prime factors is not automatically
   a minimal zero-sum sequence for this reason.

5. **Use a field norm as an integral generator.** The Hasse theorem
   still gives only a field element with possible denominators. The
   new partial-factor lemma checks each local place, then uses the
   exact accepted odd-ordinary-class unit correction on a PRINCIPAL
   balanced ideal. It does not drop principality or assert that a
   positive unit is a square. At even class number the old2-primary
   obstruction can carry the failure instead.

6. **Use classnumber1 or a small exponent universally.** Classnumber1
   is now shown to force q prime in this domain. Under odd hF every
   balanced prime-factor class has order r with ell^r>=q, so at a
   non-prime-powerq even the minus-class exponent exceeds EVERY
   exponent inq. No assertion proves these class numbers small, and
   no new q is evaluated. Large odd groups readily accommodate the
   necessary class orders and minimal zero-sum sequences.

7. **A minimal zero-sum class sequence realizes a difference set.**
   No. The actual squarefree solution gives such a sequence; an
   arbitrary sequence does not supply the correct split-prime ideals,
   a principal full product, normalized integral character or binary
   Fourier lift. A9E is one-way. There is no classgroup-combinatorics
   converse hidden in the Davenport bound.

8. **Small multiplier rigidity settles every nonsaturated set.**
   The elementary cube-root gap proves a primepower conclusion only
   under its explicit SMALL-group upper bound. The generated known
   subgroup can be larger, and the full numerical group need not be
   identified with it. No universal smallness or saturation is proved.
   No cyclic=>classical inference is made. For compositev even a
   componentwise odd-order shortcut has separate unresolved problems.

9. **More general unique-difference/field-descent theorems repair all
   square factors or prime conductors.** The inspected Duc--Schmidt2017
   operative theorem has ADDITIONAL prime-power norm, even-order and
   quantitative hypotheses. The2019 paper's special bent-function
   systems/tables likewise are not the actual difference-set input here.
   They were not imported after noticing a similar bound. The old
   field-descent squarefree-conductor weakness remains.

The remaining actual issue is a full norm-q integral generator obtained
through genuinely mixed class cancellation (and, outsideoddhF, a true
unit correction), or an obstruction excluding that cancellation in the
specified arithmetic fields. No argument here controls it for allq.
The full cyclic prime-power conjecture and official taut classification
remain open. A future advance must address that inference, not rerun
an existing filter or silently reverse a necessary class statement.
