# SQ15 failed inferences and exact remaining gap

FULL VERSION v1.1, 2026-10-18 UTC. Candidate reasoning - unverified. No mathematical
scan/CAS/table/source rerun was used; no old file was edited.

1. **Class number size alone.** SQ14's exponential lower bound does
   not contradict any supplied upper bound. Relative class groups
   at large conductor may be much larger. No new field/class group
   was evaluated and no asymptotic count is an individual exclusion.
2. **Ordinary classes replace refined labels.** The same-ideal unit
   obstruction Gamma can survive. Correcting gamma by its norm-unit
   on I is unproved; gamma²/epsilon corrects SAME I² only. The new
   ordinary-order bound uses that exact square, not a deleted parity
   hypothesis. For INTEGRAL norm-2 J, ordinary order4 REQUIRES a
   nontrivial Gamma component and is not contradicted.
3. **Two ordinary collision ranges close the mixed product.** For
   q=ab, the ordinary collision argument on INTEGRAL ideals pays balances
   a² and b². Even using the improved endpoint it would need both
   2a²<=s+1 and2b²<=s+1. Hence2q<=s+1<=q+2, so q<=2.
   This route cannot apply to BOTH factors in the new q>=3 domain.
4. **Whole actual class0 makes every component class0.** False as
   a proposed inference. The genuine norm-q ideal can be a minimal
   zero-sum of nonzero refined labels. The new result excludes
   specified low orders and small conjugate costs, not all mixed
   cancellation. No field-norm existence statement makes a chosen
   integral ideal principal.
5. **An arbitrary odd T inherits a Sidon orbit.** It must actually
   fix D. Merely containing norm-prime residues does not license
   applying the new endpoint argument to an enlargement. The pure
   arithmetic SQ14 endpoint remains only necessary without D.
6. **Discard a2/s3.** That would miss the only small branch. The
   hand argument instead proves p7/q2. We retain it as an exception,
   with no preliminary construction or unsupported nonexistence.
7. **Attempt a broad square-norm field theorem.** General circulant
   weighing/unique-difference sources may impose0,+/-1, properness,
   even-order or large-conductor hypotheses. None is silently used.
   The actual Sidon orbit supplies the extra ingredient here. No
   conductor-only classification of arbitrary square-Weil integers
   is asserted.
8. **An unneeded graph/classification detour.** At the old endpoint,
   (12) also gives special difference-support/graph identities.
   Attempting to classify these through a least-eigenvalue theorem
   would introduce substantial unverified hypotheses. The actual
   Sidon bound directly gives a<=2, so no graph-classification or
   sum-product theorem is needed or imported.
9. **Initial live prose correction, before freeze.** A draft sentence
   called 2^(s/3) a nontrivial cube root modulo p. Its residue MAY
   be1. The final proof explicitly retains1,q,q² and excludes an
   ordinary value<=p in each case. No conclusion assumes ord_p(2)=s.
   This was corrected while all SQ15 files were still unfrozen.
10. **The exact ideal stabilizer is the zero ideal-class stabilizer.**
    R8F forbids that substitution. The new cost uses the actual
    prime exponents of I and an actual integral quotient. At T=M,
    all M fix each F-ideal; for a smaller T an arbitrary ideal
    factor need not be M-invariant. The main marks this field choice.
11. **Orbitwise intervals imply an element.** They construct only
    an integral ideal factor A and balanced complement B. Neither
    factor is assigned an element, an exact norm generator or
    principality. The contradiction comes only if such A descends
    while an ACTUAL full alpha exists and its complement is small.
12. **Odd and even H.** The orbit-pair proof uses c not in H. It
    makes no claim for even H, where O and cO may coincide and an
    extra central exponent condition is required. If Gal(F/Q) has
    no nontrivial odd subgroup, SQ15D's last obstruction is vacuous.
13. **A small cost must exist for every mixed q.** Not proved. The
    actual unbounded arithmetic inference still needed is a sigma
    outside M with b_sigma<=(s+1)/2, or a nontrivial odd H and
    feasible intervals at a complement balance in that range. A
    formal array surviving the bounds is not an actual set, and a
    failure of this inference is not a counterexample to the annual
    question. This is the remaining central bridge.
14. **Published overlap/priority.** Classical Fourier orthogonality,
    Sidon differences, ideal class/unit mechanisms and SQ14 are
    attributed. The old1998 class paper remains text-unread, and
    discovery/partial source reads cannot establish absence of this
    application from the literature. No priority claim is made.

15. **The v1 universal ideal statement silently inherits integrality.**
    False. R8 defaults to fractional ideals, and TD deliberately defines
    rho for fractional balanced pairs. A correct integral-generator
    proof does not supply a missing INTEGRAL statement hypothesis. A's
    complete blind review gave the actual known q8/p73/s9 diagnostic:
    fractional J_fr=(z),zc(z)=2, has ordinary R1 and rho0, whereas
    unqualified(2)/(3) demand9<=1. No integral z exists, as the main
    independently checks using SQ15A and unramified2. This false v1
    reading is preserved, not relabelled an editorial-only change.
16. **Rho zero always gives an integral element.** It gives an exact
    generator of the SAME ideal. Integrality follows only when that
    prescribed ideal is integral. Auxiliary field-norm/Hilbert90
    factors may have denominators even in the integral proof. The new
    version never applies SQ15A to a fractional generator.
17. **Use an older unqualified norm-ell clause to avoid the repair.**
    Not valid. The same domain caution applies to the historical
    SQ14D/E wording. This version imports only its square lift and the
    independently reproduced arithmetic s>=15; integral class-order
    conclusions are rederived in full. Root/B handle any separate old
