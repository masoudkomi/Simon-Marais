## Mathematical statement

Start with the string \(1\). If an admitted string has odd length, a 0 may be added at either end; if its length is even, a 1 may be added at either end. Let \(B\) be exactly the strings generated by these operations, and let \(b_n\) count its distinct length-\(n\) strings.

**Open target, B4(b) only:** determine \(\liminf_{n\to\infty}b_n^{1/n}\) and \(\limsup_{n\to\infty}b_n^{1/n}\).

Only (b) was designated open. Count strings, not insertion histories.
