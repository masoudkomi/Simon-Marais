# FR11 meaningful failed routes and remaining inference

Candidate proof - unverified. All mathematics was hand reasoning; no
finite-field count, factor scan or generic test was run.

1. The first proposed residual family was ell21,q=2^(6t). Its root
   group lies in a fixed finite subfield and has genuine four-root
   zero sums. The old FR10 P is negative. The NEW improved count still
   gives P_U=-305q²-652q-4, so that family remains unclosed. This
   precise failure is retained; no test converse or reducibility is
   inferred. I did not compute an exact M21 table.
2. I considered replacing the EVERY-component degree lower bound q by
   a stronger generic-tangent/Gauss-map bound. The existing contact-q
   argument does not by itself yield a larger universal degree. No
   characteristic-zero reflexivity, separability or strange-curve
   classification was imported. This exploratory route produced no
   additional theorem and is NOT a premise of FR11.
3. A reversed-Dickson/difference-quotient and monodromy viewpoint was
   considered as a possible distinct route. No required transitivity,
   integral cover dictionary or component classification was proved.
   No conjectured critical-value count or external theorem replaces
   actual component geometry in the submitted proof.
4. The successful change was instead an elementary translation defect
   for a subgroup which contains F4* but is not itself a full field
   multiplicative group. It improves a count in the already accepted
   ACTUAL budget. This does not eliminate any nonordinary, ordinary
   diagonal, central or infinity case from that budget.
5. An intermediate estimate improved ONLY M_d and gave the valid but
   weaker ell105 expression31q²-41788q-4. Applying the same lemma to
   M_ell as well gives the operative31q²-40972q-4. These are successive
   hand bounds, not a repair of a frozen false theorem or a numerical
   optimizer output. Only the full latter bound is the operative family
   calculation; both preserve nonnegative count weights.
6. Strictly discounting every finite multiplicative subgroup is false:
   for s=2^a-1 the root group is F_(2^a)^* and the old count is attained.
   Nonfield AND A_s>0 are both checked before using the stricter count.
   The numerical condition3|s supplies the positive overlap; no generic
   sum-product avoidance hypothesis is assumed.
7. Literature searches returned general additive-energy/subfield work,
   but no operative quantitative theorem from those results was needed
   or imported. Such theorems often require avoiding all subfield
   cosets, which cannot be presumed here (our actual witness uses F8).
   Original inaccessible APN sources remain unread; lack of an accessible
   proof is not evidence of nonoverlap or priority.

The annual ordinary-F2 reducibility classification remains open. New
