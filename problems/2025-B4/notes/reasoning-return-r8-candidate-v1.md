Let the field have characteristic>7. Let S be finite, u:S->K^*

    7v_5+800u²v_3+4608u^5=0.                         (6)

    |S|<=30k.                                       (8)

(C_3,C_5) in R, any point in a DIFFERENT u-fiber giving this ratio

    v_3=A+C_3(X-a)³, v_5=B+C_5(X-a)^5.

    P_C(X)=7[B+C_5(X-a)^5]

used are units in characteristic>7.

    P_(v,k+1)=pD P'_(v,k)+(R_v-kpD')P_(v,k).

    deg P_(v,k)<=(p-2)k.                             (23)
