# Public-paper cache policy

The user authorized public mathematical searches, access, downloads and local caching for this project on 2026-10-16. Prefer original papers and author-posted versions. Do not incur charges, buy papers, subscribe or bypass access restrictions. Ask before any charge.

Full downloaded papers belong under ignored `.cache/official/` or `.cache/literature/<year>/`. Save citations, exact source URLs, versions, retrieval dates, hashes, short relevant excerpts and original research notes in the tracked year directories or source manifests. A paper's public availability does not establish redistribution rights. A full third-party paper may enter Git only after its applicable redistribution licence has been verified and recorded. The default `*.pdf` ignore is a precaution; any intended exception requires that check.

Four full PDFs had entered earlier 2018 review-evidence commits before this explicit caching instruction. Their bytes are preserved locally, and the current branch tree removes those copies. `literature-cache.json` maps the original immutable review commands to the replacement local paths and hashes. Earlier commits still contain the copies. No force-push or history rewrite has been performed. The mathematical review reports remain unchanged, so their recorded acceptance hashes remain reproducible.
